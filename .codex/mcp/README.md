# MCP integration contract

## Engram

Use Engram for project decisions, architecture, incidents, discoveries, conventions, and session summaries. Never store credentials or raw secrets.

## Context7

Use Context7 for current, library-specific documentation before relying on remembered APIs or configuration syntax. Record the selected library/version and relevant source in the task evidence when it affects a change.

## Configuration boundary

The MCP servers are configured at the Codex user level. This repository intentionally contains no executable server configuration, access token, or machine-specific path. Keep this document as the shared contract for agents and subagents.
