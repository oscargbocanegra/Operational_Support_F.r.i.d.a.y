# Operational Support Friday

Evidence-driven AI technical support for a mixed Linux cluster and Windows clients.

The project foundation lives in `.codex/` and includes the orchestrator, specialist subagents, reusable skills, and MCP integration contracts for Engram and Context7. The initial architecture is documented in [`docs/architecture.md`](docs/architecture.md).

This repository currently contains the operating model and documentation foundation. Runtime automation and host integrations will be added incrementally behind explicit approval and verification gates.
